Git Commands Used During the Assignment
========================================

1. git --version
   Displays the installed version of Git on the system.

2. git init
   Initializes a new Git repository in the current directory, creating a .git folder.

3. git branch -M main
   Renames the default branch to "main" to follow modern Git conventions.

4. git status
   Shows the current state of the working directory and staging area, including tracked, untracked, and modified files.

5. git add .
   Stages all new and modified files in the current directory for the next commit.

6. git add <filename>
   Stages a specific file (e.g., index.html, about.html, .gitignore) for the next commit.

7. git commit -m "message"
   Records the staged changes as a new commit in the repository with a descriptive message.

8. git branch feature
   Creates a new branch named "feature" based on the current branch.

9. git checkout feature
   Switches the working directory to the "feature" branch.

10. git checkout main
    Switches the working directory back to the "main" branch.

11. git merge feature
    Merges the changes from the "feature" branch into the current branch (main).

12. git log --oneline --graph --all
    Displays a compact commit history with a graphical representation of branches and merges.

13. git log --all --decorate
    Shows the full commit history with branch and tag labels for all branches.

14. git reset --soft HEAD~1
    Undoes the last commit but keeps the changes staged in the staging area.

15. git reset HEAD <filename>
    Unstages a specific file, moving it from the staging area back to the working directory.

16. git checkout -- <filename>
    Discards changes in the working directory for a specific file, restoring it to the last committed state.

17. git remote add origin https://github.com/SuteerthSK/GameVault.git
    Links the local repository to the remote GitHub repository.

18. git push -u origin main
    Pushes the main branch to the remote repository and sets it as the upstream tracking branch.

19. git config user.name "SuteerthSK"
    Sets the Git username for commits in this repository.

20. git config user.email "suteerthsk@gmail.com"
    Sets the Git email address for commits in this repository.
